Typography & eyebrows

Three roles: Applied Sans Display (headings), Applied Sans Text (UI/labels), XCharter serif (prose). Hierarchy comes from size, weight, and space — not color or extra fonts.

Eyebrow · all-caps mono

Heading level two

Heading level three

A lead paragraph (standfirst): larger serif on a tight measure for the opening claim of a section.

Body prose in XCharter. Confidence comes from specificity — a highlighted claim marks the one thing that matters. Use bold sparingly and a link where useful.

Snippet
<p class="eyebrow">Eyebrow · all-caps mono</p>
<h2>Heading level two</h2>
<p class="lead">A lead paragraph.</p>
<p>Body prose with a <mark class="hl">highlighted claim</mark>.</p>

BibTeX (copy button)

The house pattern: a BibTeX action button that copies a hidden <pre id="bibtex-src"> to the clipboard and flashes "BibTeX copied". No visible code block. Put the button in the hero .actions row; main.js wires it.

  title   = {Project Name},
  author  = {Author One and Author Two},
  journal = {arXiv preprint},
  year    = {2026}
}

Charts

Six chart types, one system

Every chart is declarative: a .chart host with data-chart="<type>" and data-src="<json>". The library animates on scroll-in, shows exact values on hover, toggles series from the legend, and falls back to data-fallback image if the JSON fails. The hero series is blue; others are neutral, told apart by texture/dash/marker — not by a second hue. Full JSON schemas live in the skill's references/charts.md.

Bar — grouped & stacked

Benchmark comparisons. Set "mode": "stacked" for composition. Try the legend toggles.

Snippet
<div class="chart-wrap">
  <div class="chart" data-chart="bar"
       data-src="assets/data/bar.json"
       data-fallback="assets/figures/bar.png"></div>
</div>
<script src="assets/js/charts.js"></script>

Line — multi-series

Training curves, scaling laws. Solid blue hero line draws on; neutral lines use dash patterns.

Snippet
<div class="chart" data-chart="line" data-src="assets/data/line.json"></div>

Scatter — with optional bubble size

Pareto fronts, ablations. A 3rd value per point scales bubble area. Series use distinct marker shapes.

Snippet
<div class="chart" data-chart="scatter" data-src="assets/data/scatter.json"></div>
<!-- points: [x, y] or [x, y, size] for bubbles -->

Area — stacked or overlapping

Cumulative composition over time. "mode": "overlap" for translucent overlays.

Snippet

Leaderboards and ranked comparisons. The highlighted item is blue.
