Method

The scene memory lives inside the backbone

1

Tokenized streaming reconstruction

The scene is a set of latent spatial tokens. After every frame they are decoded into 3D Gaussians: a reconstruction of everything seen so far, at every step.

2

One image per step, no KV cache

Each step sees only the current frame. Past frames are not kept or re-attended; the latent spatial tokens are the only state carried to the next step.

3

Adaptive token length

The number of latent spatial tokens is not fixed: each step updates the existing tokens and admits only the selected tokens of the new frame.
